# ADR: Zod for Runtime Validation and Schema Definitions

**Status**: adopted  
**Date**: 2024-01-23

## Context

We need runtime validation for:
1. API request/response payloads
2. Environment variables
3. Form inputs
4. Drizzle ORM integration via drizzle-zod

## Decision

We will use **Zod** for all runtime validation needs.

## Consequences

- TypeScript-first schema validation
- Excellent error messages out of the box
- Seamless integration with drizzle-zod
- Validated schemas act as documentation
- Slight runtime overhead (acceptable for validation)

## Alternatives Considered

1. **Yup**: Mature but less TypeScript-native
2. **Joi**: Great but Node.js-only
3. **io-ts**: Functional programming style, steeper learning curve
4. **Z**: Minimal but less ecosystem support
